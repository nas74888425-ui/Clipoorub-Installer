# Клипоруб — публичный сайт

Здесь только статическая витрина, не исходники приложения.

Три режима: без ИИ, встроенный локальный КЛИПОРУБ AI, необязательный платный Яндекс.
Бета имеет общий срок 30 дней от сборки, который не продлевается переустановкой.

Кнопка полного установщика появится после проверки новой Windows-сборки и размещения единого EXE.
GitHub Releases допускает каждый файл только менее 2 GiB, поэтому большой полный EXE может потребовать внешнее хранилище.
