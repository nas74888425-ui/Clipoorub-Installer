Три способа отбора в одном приложении. Режим можно менять под задачу.

БЕЗ ИИ / БЕЗ КЛЮЧЕЙ

Поиск по сигналам

Всплески чата, звука и движения помогают найти активные моменты. Простой титул берётся из доступной речи или чата. Генеративная модель не используется для отбора.

Для локального файла интернет не нужен. Субтитры распознаются отдельно локально, если включены.

КЛИПОРУБ AI / ЛОКАЛЬНО

Кадры + речь + чат

Встроенная модель оценивает окна-кандидаты по видео, речи и доступному чату, выбирает законченные события. Создаёт заголовок, титул, описание и хештеги.

Без платы за API, Ollama и отдельного скачивания моделей. Требовательнее к компьютеру. Это не полный просмотр каждого кадра.

ЯНДЕКС / ПО ЖЕЛАНИЮ

Глубокий облачный анализ

Анализ распознанной речи обрабатываемой записи и чата, отбор по смыслу, заголовки с хештегами и цепляющие титулы. Понадобятся ключ и доступ к Yandex Cloud.

Платный API по тарифам Яндекса. Текст речи и чата отправляется в облако. Перед запуском — предупреждение; может работать дольше.

Честно о бете

Это бесплатно? Нужны ли ключи?

Приложение бесплатно в пределах объявленного срока беты. Режим без ИИ и КЛИПОРУБ AI не используют платные API. Отдельный режим Яндекс сохранён: он требует ключи и оплачивается по тарифам Яндекса. Для Twitch и загрузки записей нужен интернет.

Видео отправляется на сервер?

В режиме КЛИПОРУБ AI видео, кадры и речь обрабатываются локально. Сайт не принимает записи. Модель готовая — Qwen3-VL 4B; она не обучалась нами с нуля.

На любом компьютере будет быстро?

Нет. Рекомендуем 16 ГБ оперативной памяти и совместимую видеокарту с актуальным драйвером Vulkan. Есть запасной запуск на CPU, но он заметно медленнее. Скорость зависит от записи и оборудования; начни с короткого теста.

ИИ точно найдёт все лучшие моменты?

Это бета: анализируются окна-кандидаты, а не каждый кадр длинного стрима. ИИ может пропускать события и ошибаться в подписях. Проверяй текст и клипы перед публикацией.

Можно ли продлить срок переустановкой?

Нет. У этой беты единая дата окончания, закреплённая при сборке, а не счётчик первого запуска. После окончания потребуется новая доступная версия. На старые ранее выпущенные сборки эти условия задним числом не распространяются.

Исходники станут публичными?

Нет. Страница загрузки размещается отдельно от приватного репозитория приложения. Для установки исходный код и доступ к GitHub не нужны.
